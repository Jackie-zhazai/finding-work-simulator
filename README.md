# Finding Work / FW 模拟器

计算机学生求职人生模拟、路线探索与 MiMo 解析。项目创建于 E:\FindingWork。

线上试玩：[fw.jobspark.website](https://fw.jobspark.website)。比赛演示、Agent 组织架构和匿名运行证据见 [submission](submission/README.md)。

生产站对应的游戏代码提交为 `23b5c49`。随机模式有 16 个主节点，定制模式有 26 个主节点，收到机会时会由玩家确认是否接受。

## 本地运行

安装依赖后执行 `npm run dev`。运行 `node scripts/test-game.mjs` 验证引擎，`npx tsc --noEmit` 检查类型，`npm run build` 生成生产构建。

在忽略文件 `.dev.vars` 中配置 MiMo Key。不要把真实密钥写进本文件或 Git。默认模型为 `mimo-v2.6-pro`，实际权限以资源账户为准。密钥在用户本轮明确提供后配置，未进入源码。

## 已实现

- 随机/定制模式，六种起始年级、学生档案。
- 按阶段、路线和地区抽取情境，推进到实际毕业两年后。随机模式 16 个主节点，定制模式 26 个主节点，岗位确认按实际机会出现。可以留在开发、转方向、升学或休整。
- 角色档案可以自由随机或锁定关键背景。连续重开优先避开近期档案和事件；结局记录城市、工作或升学状态、关键选择与下一步。
- 转向、升学、延期、过渡就业和休整；终点为更新后毕业节点的两年之后。
- 暂停、1—16倍速、下一抉择、收起事件、键盘选择、浏览器存档。
- 结局时间线、匿名分享图、记录导出、反馈导出。
- 服务端 MiMo 指导、解析→检查→有限修改流程、反馈整理。
- 模型未配置/超时/格式失败时明确说明，基础游戏可用。

## 当前边界

- 存档、反馈、调用摘要按浏览器保存，没有全站用户数据库。
- 服务端接收并校验客户端模拟快照；不是可信履历或防作弊系统。
- 没有微信登录、支付或严格的每人一次控制。
- 事件与概率为原创游戏设定，不代表真实就业统计；学校和性别不直接加减能力。
- 考试与公共服务、自由协作等去向采用简化规则。
- 内存限流仅为 Demo 保护，跨实例限流需部署级存储。
- 生产环境已验证真实 MiMo 途中指导与行动单；脱敏记录见 [演示运行证据](submission/FW-demo-agent-evidence.json)。
- 不预装第三方素材。视觉参考 character-ocean，但 Canvas 字符背景为原创实现。
