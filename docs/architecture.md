# 架构与数据边界

React 客户端展示与时间控制；lib/game.ts 为确定性状态引擎；app/api/agent 为服务端编排入口；lib/runtime.ts 将 Worker 环境绑定提供给服务端代码。

MiMo 使用服务端环境变量，API 输出不直接修改状态。解析生成→结构检查与模型审阅→必要时修改→再次审阅→引用ID验证→交付。任务只记录摘要，不展示私有思考过程。

隐私：调用时发送当前角色背景、模拟记录和用户消息；不会自动读取其他文件、发送宣传或创建交易。匿名分享图不包含姓名与聊天。

存储：浏览器 localStorage。未实现跨设备同步、中心反馈收集或可信后端游戏会话，页面与 README 明确说明。

上线默认 owner-private。公开访客访问需要后续明确设置受众，并补齐持久限流和费用控制。
